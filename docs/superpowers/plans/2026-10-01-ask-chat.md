# Ask Chat with Kiwi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax. Each task: write the failing test, run it, implement, run it, commit.

**Goal:** Kiwi, a round speaking bot, chats (max 6 turns) to confirm the request before running the existing voice-ask search.

**Architecture:** New `POST /api/ask/chat` (DeepSeek structured output, quota kind `chat`) returns one turn. The client keeps the thread, speaks Kiwi's lines, listens continuously, and on confirmation calls the existing `/api/ask`.

**Tech Stack:** as in `2026-10-01-voice-ask.md`. Spec: `docs/superpowers/specs/2026-10-01-ask-chat-design.md`.

## Global Constraints

- Max 6 user turns; 12 messages; message text ≤ 300; reply ≤ 200; quick replies 0–4, each ≤ 30.
- DeepSeek `deepseek-flash`, `providerOptions: DEEPSEEK_NO_THINKING`, chat timeout 6 s.
- Chat turns never consume search quota; `chat_per_day` default 60; `per_minute` 20.
- No `radial-gradient`; radius tokens only; CRLF files; no AI co-author; one commit per task.
